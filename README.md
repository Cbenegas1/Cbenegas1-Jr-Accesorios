# JR Motors

Landing page profesional para un negocio automotriz
ubicado en Caacupé, Paraguay.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Responsive Design

## Funcionalidades

- Diseño responsive
- Animaciones
- Formulario de contacto
- Integración con WhatsApp
- Google Maps
- Galería
- Redes sociales

## Objetivo

Crear una presencia digital profesional para un
negocio automotriz y facilitar el contacto con
clientes potenciales.
