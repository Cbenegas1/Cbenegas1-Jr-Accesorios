# 🚗 JR Accesorios — Sitio Web Profesional

![JR Accesorios](https://cbenegas1.github.io/Cbenegas1-Jr-Accesorios/)

Sitio web moderno y responsive desarrollado para **JR Accesorios**, un negocio dedicado a accesorios, equipamiento, iluminación LED, car audio, tuning y personalización automotriz.

El proyecto fue diseñado con un enfoque **visual, moderno y orientado a clientes**, facilitando la presentación de servicios y el contacto directo mediante WhatsApp.

## ✨ Características

- 📱 Diseño completamente responsive.
- 🖥️ Adaptado para computadoras, tablets y celulares.
- 🍔 Menú de navegación móvil interactivo.
- ⚡ Animaciones y efectos visuales.
- 🚗 Presentación de servicios automotrices.
- 💡 Sección de iluminación y accesorios.
- 🔊 Servicios relacionados con car audio.
- 🏁 Sección orientada al tuning y personalización.
- 📲 Integración con WhatsApp.
- 📝 Formulario de contacto.
- 🔢 Contadores animados.
- 🎨 Modo visual Neón.
- ⬆️ Animaciones al hacer scroll.
- ⚙️ JavaScript para interacciones dinámicas.
